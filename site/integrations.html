QuantumBridge integration

Local-only signal bridge

QuantumBridge can read JARVIS market state and research signals from a small localhost API. Both applications must be running on the same computer.

Safety boundary: The JARVIS plugin exposes paper-research signals only. It does not expose credentials, place orders, or enable real trading. Keep both services bound to localhost.
Connection steps
  1. Start JARVIS V3.5
    Run the local workshop and confirm its dashboard opens on 127.0.0.1:5000.
  2. Start QuantumBridge locally
    Run its local app/API proxy on localhost:5173. The public website cannot provide this server-side bridge.
  3. Open Connection Options
    Choose JARVIS Link, then select Connect JARVIS to load the current paper-signal snapshot.
  4. Review, do not automate
    Treat signals as informational. Research gates can return HOLD, and results do not demonstrate a trading edge.
