cBot Builder and plugins

Concept: not built yet

Two ideas planned for JARVIS V3.5. This page sketches them so the decisions can be made before any code is written.

cBot Builder

A guided way to build bots for cTrader.
1. Choose a template
2. Set parameters and risk limits
3. Review the generated cBot code
4. Export it for cTrader

To decide: which templates, whether the code is generated or edited by hand, and how it is tested before export.

Plugin access

Proposed rule: a plugin gets capabilities, never credentials.
PermissionProposed
Read market datag
Read paper resultsg
Propose a signalg
Read credentials or tokensr
Place ordersr
Open network connectionsr

Plugins would run in the same sandbox as imported bots.
